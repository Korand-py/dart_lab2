## Ответы на вопросы

1. В чём разница между полем класса и обычной переменной в функции?
	Разница заключается в области видимости, времени жизни в памяти. Полем класса могут пользоваться все методы, а переменной функции можно воспользоваться только при работе этой самой функции.
2. Что такое конструктор и зачем он нужен?
   **Конструктор** — это специальная функция внутри класса, которая вызывается **всего один раз**. Конструктор задает начальные настройки для объекта класса. 
3. Зачем нужен @override перед toString()? Что будет если его убрать?
   Тег @override нужен для переопределения функции, чтобы заменить её стандартное поведение. Если убрать данный тег, то программа продолжит работать точно также и выводить костюмный текст. Однако без этого тега пропадет защита от опечаток.
4. Чем статическое поле static int _counter отличается от обычного поля?
    - **Обычное поле** принадлежит **конкретной копии** класса (объекту). У каждого созданного объекта это поле своё собственное.
	- **Статическое поле (`static`)** принадлежит **самому классу** целиком. Оно существует в единственном экземпляре на всю программу, и все объекты этого класса делят его между собой. В программе существует ровно одна копия этого поля.
5. Что означает нижнее подчёркивание в _counter?
     В языке программирования Dart нижнее подчеркивание в начале имени означает, что поле или переменная является приветной.
